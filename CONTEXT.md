# BrainCo package vocabulary

- Model descriptor: canonical named radians metadata, independent of native FK.
- Offline controller: package-owned epoch authority for one synthetic/replay hand.
- Issued action: target admitted and successfully sent to the mock interface.
- Observation: independent mock readback, available outside active epochs.
- Derived full positions: Revo2 mimic expansion, not independent measurements.
- Source timestamp: Unix capture time; host timestamp: Unix publication time.
- Control clock: monotonic scheduling, watchdog, freshness and solve deadlines.
- Epoch: never-reused session identity fencing old solves and control requests.
- Qualification gate: physical activation remains unavailable without separate
  model/firmware/transport/SDK/axis/limits/readback/stop qualification.
